# Hear when a turn finishes

Noyau can play a sound when an agent finishes a turn.

## Choose a turn-end sound

1. Open **Settings**.
2. Select **General**.
3. Turn on **Turn end sound**.
4. Select the sound you want to hear.

Selecting a sound plays a preview.

## Turn the sound off

Turn off **Turn end sound** in **Settings** → **General**.
